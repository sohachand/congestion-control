Slow start doubles cwnd every round-trip (exponential) until it crosses ssthresh. Congestion avoidance then grows it by one segment per RTT (linear) — probing gently for more bandwidth. A loss means the pipe is full: ssthresh is halved, and Tahoe drops cwnd back to 1 and restarts slow start, while Reno's fast recovery resumes directly from the new ssthresh.

Controls

Losses also fire randomly (~3% per round) once cwnd climbs past ssthresh, so the saw-tooth keeps renewing on its own — or force one yourself to watch the recovery path.

Packets arrive in bursts, however fast the source wants. The bucket queues them and leaks packets out at a fixed rate, no matter how full it is — so output is always smooth. If arrivals outpace the leak rate for long enough, the bucket overflows and drops the excess: output rate is capped, but bursts are not tolerated.

Tokens accumulate at a fixed rate up to the bucket's capacity. A packet can leave only if it finds a token to spend. Unlike the leaky bucket, an idle bucket banks tokens — so when traffic finally arrives it can burst out at full speed until the saved tokens run out, then settles to the token rate.

How to read it: the link can only pass capacity packets per round. Anything extra waits in the queue. When the queue is full, new packets are dropped, and the senders re-send them, making things worse.

OFF: senders ignore the network and keep blasting. ON: each sender uses TCP's rule: speed up gently, and cut its speed in half when it loses packets.
